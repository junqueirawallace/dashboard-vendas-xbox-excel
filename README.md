# Dashboard de Vendas do Xbox com Excel

## Visão geral
Projeto educacional de análise e visualização de dados no Microsoft Excel. O objetivo é organizar registros de assinaturas relacionadas ao ecossistema Xbox e transformá-los em indicadores e gráficos.

> **Importante:** os arquivos de apoio `base.xlsx` e `dashboard_xbox_finalizado.xlsx` não estavam disponíveis. Esta versão usa uma **base demonstrativa fictícia**, criada para fins de estudo. Os valores não são dados oficiais da Microsoft/Xbox e não devem ser apresentados como resultados reais.

## Arquivos
- `dashboard_vendas_xbox.xlsx` — dashboard, base demonstrativa e análises.
- `README.md` — documentação do projeto.

## Abas da planilha
- **Dashboard:** indicadores e gráficos.
- **Base de Dados:** registros fictícios com data, plano, tipo de assinatura, renovação, complementos, descontos, valor total, país e plataforma.
- **Análises:** resumos mensais, vendas por plano e contagem de renovação automática.

## Indicadores
- Faturamento total demonstrativo.
- Quantidade de assinaturas registradas.
- Ticket médio por assinatura.
- Percentual com renovação automática.
- Vendas por plano.
- Evolução mensal das vendas.
- Distribuição por renovação automática.

## Como abrir e reproduzir
1. Baixe `dashboard_vendas_xbox.xlsx` e abra no Microsoft Excel.
2. Consulte a aba **Base de Dados**.
3. A aba **Análises** contém fórmulas que alimentam os gráficos.
4. A aba **Dashboard** apresenta a visão consolidada.
5. Para usar dados reais, substitua os registros mantendo as colunas e revise os intervalos das fórmulas.

## Recursos utilizados
Microsoft Excel, tabela estruturada, filtros, fórmulas `SUMIFS`, `COUNTIFS`, `SUMIF`, `COUNTIF` e `AVERAGE`, gráficos de colunas, linha e rosca.

## Limitações
Esta versão foi criada sem acesso à base e ao dashboard de referência do curso. Os dados, indicadores e layout podem não corresponder exatamente ao modelo oficial. Para uma entrega fiel, substitua a base fictícia pela base original quando disponível.

## Objetivo de aprendizagem
Praticar organização de dados, criação de indicadores, visualização de informações e documentação de um projeto para portfólio no GitHub.
